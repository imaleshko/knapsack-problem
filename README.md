# Задача рюкзака

Інтерактивний візуалізатор розв'язання задачі про рюкзак (0/1 knapsack) п'ятьма методами.
Показує не лише відповідь, а й хід кожного алгоритму.

## Методи

| Метод                   | Складність         | Точність   |
|-------------------------|--------------------|------------|
| Грубої сили             | O(2ⁿ · n)          | Точний     |
| Рекурсивний             | O(2ⁿ)              | Точний     |
| Динамічне програмування | O(n · W)           | Точний     |
| Жадібний                | O(n · log n)       | Наближений |
| Гілок і меж             | O(2ⁿ) у найгіршому | Точний     |

*n — кількість предметів, W — місткість рюкзака.*

## Технології

- React
- TypeScript

## Запуск

```bash
npm install
npm run dev
```
